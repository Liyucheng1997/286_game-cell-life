# 细胞的一生 · A Cell's Life

一个用 Three.js 构建的科普小游戏：选择一种人体细胞，亲身经历它从诞生到谢幕的完整一生。

## 运行

- 直接双击打开 `index.html` 即可（Three.js 通过 CDN 加载，需要联网）。
- 或者在本目录起一个静态服务器：

```bash
python -m http.server 8765
```

然后访问 http://localhost:8765 。

## 玩法

- **WASD / 方向键** 移动，**空格** 互动
- 每种细胞有 5 个阶段：诞生 → 成熟/生长 → 工作 → 战斗/分裂 → 终点
- 每阶段开始有剧情介绍，完成任务后弹出「你知道吗」知识卡
- 全部完成后展示该细胞的一生时间线

| 细胞 | 亮点任务 |
| --- | --- |
| 🩸 红细胞 | 骨髓合成血红蛋白 → 脱核 QTE → 肺泡载氧 → 毛细血管送氧 → 脾脏被巨噬细胞回收 |
| 🛡️ 中性粒细胞 | 装填颗粒 → 血流中追踪趋化因子 → 滚动/黏附/穿出血管 → 追捕吞噬细菌 → 凋亡成脓 |
| ⚡ 神经元 | 沿放射状胶质迁移 → 轴突导航 → 建立突触 → 动作电位节奏小游戏 → 终身服役 |
| 🧱 上皮细胞 | G1 生长 → S 期复制 DNA（避开自由基） → 有丝分裂四期 QTE → 肠绒毛吸收 → 顶端凋亡脱落 |
| 💪 肌细胞 | 成肌细胞融合成多核肌管 → 组装肌节（Z 盘/粗肌丝/细肌丝）→ 神经-肌肉接头节奏收缩 → 运动供能避乳酸 → 衰老与肌少症 |
| 🍽️ 巨噬细胞 | 骨髓装填溶酶体 → 出血管并分化 → 伤口胞葬清理碎片 → 消化/装载 MHC-II/激活 T 细胞 → 长期驻守 |
| ✨ 造血干细胞 | 胚胎期迁徙归巢 → 龛位静息收集信号 → 不对称分裂 QTE → 谱系细胞因子决策避辐射 → 一生的造血源泉 |

## 文件结构

- `index.html` — 页面、样式与游戏引擎（任务系统、HUD、Bloom 后处理、主循环）
- `data.js` — 所有科普内容与关卡配置（数据驱动，新增细胞类型只需在这里加一项）
- `models.js` — 细胞模型（噪声起伏的膜、核仁/线粒体/内质网/高尔基体/微绒毛/肌节/伪足等）、物品模型、QTE 与过场动画
- `envs.js` — 13 个场景（骨髓、肺泡、毛细血管、脾脏、血管、感染灶、皮层、上皮、细胞核、肠绒毛、肌肉、伤口、干细胞龛）

## 添加新细胞

在 `data.js` 的 `CELL_DATA` 数组中新增一项，`stages` 中每个阶段指定：

- `env`：场景（`marrow / lung / capillary / spleen / vessel / infection / cortex / epithelium / nucleus / villus / muscle / wound / niche`）
- `mission.type`：`collect`（收集，可选 `ordered / flee / hazards / trail`）、`deliver`（运送）、`qte`（按空格分步动画）、`timing`（节奏，可选 `visual:'motor'` 运动神经元版本）、`cinematic`（过场字幕）
- `intro / objective / tips / facts`：剧情、目标、提示、知识卡
- 新细胞的 3D 模型在 `models.js` 的 `buildPlayer` 里按 `id` 添加一段；新场景在 `envs.js` 的 `ENV` 里加一个函数
